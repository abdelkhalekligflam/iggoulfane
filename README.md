# IGGOULFANE

Premium multilingual showcase website for the IGGOULFANE Moroccan honey cooperative.

## Stack
Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Lucide React

## Languages
English · Français · العربية (RTL)

## Local development
```bash
npm install
npm run dev
```

## Production configuration
Copy `.env.example` to `.env.local` and add the confirmed values when available:

```env
NEXT_PUBLIC_SITE_URL=
NEXT_PUBLIC_WHATSAPP_NUMBER=
```

Confirmed public details: natural honey, 1 kg, 300 MAD, Tabounte (Ouarzazate), and WhatsApp ordering. Stitch concept visuals are temporary references until real cooperative photography is available.
